# JH01 RV Persistence — temporal empirical replication preregistration

This artifact freezes one outcome-blind confirmatory question: whether the
already defined JH01 RV-persistence association is observed on the fixed,
genuinely new daily decision sample from 2025-07-20 through 2026-07-19.

The exact ordered 20-symbol panel, hourly log-return construction,
equal-weight market return, RV24 feature/outcome definitions, OLS-with-
intercept estimator, Bartlett/Newey-West lag rule, and single-hypothesis
classification are all recorded in `preregistration.json`. The JH01 source
identity is bound with both semantic and source-byte digests.

This phase has not accessed replication-period market data, materialized
inputs, constructed features or outcomes, or run a regression. It creates no
Jigsaw evidence piece and grants no materialization, execution, State Snapshot,
Router, Qnty, strategy, trading, causal, or promotion authority. A later phase
must separately authorize input materialization before the frozen contract can
be evaluated.
